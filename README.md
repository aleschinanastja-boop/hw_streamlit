# Анализ температурных данных и мониторинг текущей погоды

Учебный проект по анализу исторических температурных данных и сравнению текущей температуры с историческими сезонными значениями.

Приложение позволяет выбрать город, изучить динамику температуры, сезонные закономерности и аномалии, а также получить текущую погоду через OpenWeatherMap API.

## Возможности проекта

- загрузка исторических данных из CSV-файла;
- выбор города из выпадающего списка;
- расчёт скользящего среднего температуры с окном 30 дней;
- расчёт среднего значения и стандартного отклонения для каждого сезона;
- выявление температурных аномалий;
- построение интерактивного временного ряда;
- отображение сезонных температурных профилей;
- получение текущей температуры через OpenWeatherMap API;
- сравнение текущей температуры с историческим диапазоном для соответствующего сезона;
- обработка некорректного или отсутствующего API-ключа;
- сравнение последовательного и параллельного анализа данных;
- сравнение синхронного и асинхронного способов получения данных из API.
